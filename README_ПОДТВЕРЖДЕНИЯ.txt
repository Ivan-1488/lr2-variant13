ПОДТВЕРЖДЕНИЕ ЛР № 2 ДЛЯ ПРЕПОДАВАТЕЛЯ

В проект уже добавлены проверочный ресурс /api/disease/, индивидуальный токен,
заголовок X-Verify-Hash, подтверждение и soft delete для билетов.

Чтобы получить именно настоящие результаты, сначала опубликуйте этот проект
на Render (render.yaml). Для публикации требуются доступ к GitHub и вашему
Render-аккаунту. Само наличие render.yaml не означает, что сервис развернут.

После публикации выполните на компьютере, где доступны curl и Python:

python collect_submission_evidence.py https://ВАШ-АДРЕС.onrender.com --delete-id 1

Скрипт создаст папку evidence_lr2:
01_POST_curl_i.txt – настоящий curl -i с ответом 201 и id
02_GET_curl_i.txt  – настоящий curl -i с ответом 200 и X-Verify-Hash
03–05 – настоящие результаты DELETE (400, 204) и последующего GET (404)
CHECK_SUMMARY.txt – подтвержденное совпадение хэшей или сообщение об ошибке

В итоговый отчет должны войти выводы 01_POST и 02_GET, а также скриншот
результата DELETE. Скриншот нужно получить с реального работающего API.
После получения результатов их можно вставить в DOCX и повторно вывести в PDF.

ВАЖНО: данные проверки на сайте хранятся в памяти одного процесса. Если сервис
перезапущен между POST и GET, запись может исчезнуть. Не используйте несколько
независимых worker-процессов для такой демонстрации.
